# Free tools for the boring, expensive questions

Four single-purpose web tools, no accounts, no paywalls, no app installs. Each one answers one question in the unit you already have.

| Question | Tool |
|---|---|
| What does this appliance error code mean, and can I fix it myself? | [ApplianceFix](https://appliance.bapbbopgi.com/) — 318 codes across 35 brand-and-appliance combinations, with a 1–5 DIY difficulty score |
| How many cubic yards of mulch, topsoil or gravel do I need? | [YardCalc](https://yard.bapbbopgi.com/) — cubic yards, tons, bag counts and a pickup payload check |
| Can my dog or cat eat this? | [PawsSafe](https://pet.bapbbopgi.com/) — Safe / Caution / Toxic with portions sized to your pet's weight |
| Which USPS flat rate box fits, and is it the cheapest option? | [BoxFit](https://box.bapbbopgi.com/) — all 7 flat rate boxes against your packed item, compared with Ground Advantage |

Why these four: each is a question where the authoritative data is public but awkward — a service manual, a bulk-material price sheet, a veterinary toxicology table, and USPS Notice 123 — and where a wrong guess costs real money.
