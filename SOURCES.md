# Sources

Each tool is built on public, authoritative references. The pages on each site link to the specific document they use; this file lists the main ones.

| Tool | Site | What the numbers come from | Main sources |
|---|---|---|---|
| ApplianceFix | [appliance.bapbbopgi.com](https://appliance.bapbbopgi.com/) | Manufacturer error-code tables and service/technical manuals | [LG help library](https://www.lg.com/us/support/help-library/lg-washer-error-codes--20150140270078) · [Samsung US troubleshooting](https://www.samsung.com/us/support/troubleshoot/TSG10000997/) · [Bosch error codes](https://www.bosch-home.com/us/owner-support/error-codes/dishwashers) · [GE Appliances support](https://www.geappliances.com/ge/service-and-support/) · [Whirlpool manuals](https://www.whirlpool.com/services/manuals.html) · [Maytag manuals](https://www.maytag.com/services/manuals.html) · [Frigidaire owner center](https://www.frigidaire.com/en/owner-center) |
| YardCalc | [yard.bapbbopgi.com](https://yard.bapbbopgi.com/) | Cubic-yard volume math, recommended depths, and material densities (tons per cubic yard) | [Iowa State Extension: how much mulch](https://yardandgarden.extension.iastate.edu/how-to/how-determine-amount-mulch-needed-garden-bed) · [Iowa State Extension: mulch depth](https://yardandgarden.extension.iastate.edu/faq/how-deep-should-mulch-layer-be-around-trees-and-shrubs) · [Penn State Extension: compost top-dressing](https://extension.psu.edu/using-composts-to-improve-turf-performance) · [CPSC Public Playground Safety Handbook](https://www.cpsc.gov/s3fs-public/325.pdf) · published density ranges from aggregate and landscape suppliers |
| PawsSafe | [pet.bapbbopgi.com](https://pet.bapbbopgi.com/) | Veterinary toxicology references for Safe / Caution / Toxic ratings and dose thresholds | [ASPCA Animal Poison Control](https://www.aspca.org/pet-care/animal-poison-control) · [Merck Veterinary Manual: food hazards](https://www.merckvetmanual.com/special-pet-topics/poisoning/food-hazards) · [Merck: chocolate toxicosis](https://www.merckvetmanual.com/toxicology/food-hazards/chocolate-toxicosis-in-animals) · [Merck: xylitol toxicosis](https://www.merckvetmanual.com/toxicology/food-hazards/xylitol-toxicosis-in-dogs) · [Merck: allium toxicosis](https://www.merckvetmanual.com/toxicology/food-hazards/garlic-and-onion-allium-spp-toxicosis-in-animals) · [Pet Poison Helpline](https://www.petpoisonhelpline.com/) |
| BoxFit | [box.bapbbopgi.com](https://box.bapbbopgi.com/) | USPS Priority Mail Flat Rate box dimensions and prices, Ground Advantage rates | [USPS Notice 123 price list](https://pe.usps.com/text/dmm300/Notice123.htm) · [USPS price change page](https://pe.usps.com/PriceChange/Index) |

Prices and codes change. Each site shows the date its data was last checked; if you spot an outdated value, open an issue in this repository.
